ABOUT THE PROJECT

Formula 1 Race Intelligence is a data visualization project developed using Tableau Public. Its objective is to present Formula 1 racing information through interactive dashboards and analytical views. The project focuses on exploring historical racing performance, driver comparisons, constructor analysis and championship trends across the selected 2010–2026 analysis period. This website provides direct access to the published Tableau dashboard and acts as a presentation page for the project.
